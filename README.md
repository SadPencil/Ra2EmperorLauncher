# RA2 / RA2MD / Emperor Launcher

An Object Pascal launcher for *Red Alert 2*, *Yuri's Revenge* and *Emperor: Battle for Dune*, migrated from the C# project [SadPencil/Ra2md-Launcher-CSharp](https://github.com/SadPencil/Ra2md-Launcher-CSharp). Each program is a
drop-in replacement for the retail launcher of its game.
